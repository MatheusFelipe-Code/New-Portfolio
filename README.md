## 💻 Projetos em Destaque

Neste repositório e no meu perfil do GitHub, você encontrará projetos que demonstram minha capacidade de integrar sistemas e criar soluções funcionais:

### 1. Integração Salesforce + ReceitaWS 🏢
Projeto de automação de cadastro de empresas dentro do Salesforce. Consome dados da API pública ReceitaWS e realiza o mapeamento direto do JSON para os campos de `Account` utilizando Integration Procedures.

### 2. Projeto de Clima em Tempo Real 🌤️
Aplicação backend desenvolvida em **Java** que realiza o consumo e o parsing de JSON da `WeatherAPI`, exibindo dados meteorológicos e informações de clima ao vivo.

### 3. Calculadora de IMC Desktop ⚖️
Aplicação desktop construída inteiramente com **Java** e a biblioteca gráfica **JavaFX**, focada no cálculo do Índice de Massa Corporal através de uma interface de usuário interativa.

### 4. Projeto Wiki do Yu-Gi-Oh 🎲
Para tornar o aprendizado mais dinâmico, uni meu hobby por Yu-Gi-Oh com a programação:
* **Wiki do Yu-Gi-Oh:** Uma wiki completa para consulta de cartas e informações detalhadas sobre o universo do jogo.

## ⚙️ Como executar este projeto

Caso queira rodar o portfólio localmente na sua máquina para explorar a estrutura ou realizar modificações:

1. Clone este repositório:
   ```bash
   git clone https://github.com/MatheusFelipe-Code/New-Portfolio.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd New-Portfolio
   ```
3. Abra o arquivo `index.html` (localizado dentro da pasta `src`) diretamente no seu navegador, ou utilize a extensão **Live Server** do VS Code para uma melhor experiência de visualização.
